2つのプレイヤーは[FAMILY.md](../FAMILY.md)で定めた同じ機能リストに沿って作られており、この表は両方のREADMEで同じです。「予定」はまだ実装していない作業を表します。コンソールが搭載できない機能には、ハードウェア上の理由とともに「対応不可」と記載しますが、現時点で該当するものはありません。

| 機能 | Neo Geo | Master System |
|---|---|---|
| 動画ファイルからカートリッジまで1コマンドで作成 | はい | はい |
| 映像が画面全体を埋める。全体を覆うように拡大縮小してクロップ | はい。`--fit letterbox`はまだ残っていますが、削除予定です | はい |
| ソースに焼き込まれた黒帯を検出してクロップ | はい | はい |
| 収まるまで映像と音声を最高品質から段階的に下げる | はい。`--quality search`が35段のラダーを下へ順にベイクし、音声は収まる範囲で最も高いレートを選びます | 予定。レート、ノイズ除去、再利用はベイクごとに測定しますが、カートリッジに収まるよう映像を段階的に下げる処理はまだありません |
| 追加ハードウェアなしで最大の標準カートリッジ | はい。128 MiBのキャラクターROM | はい。1 MB。Segaのマッパーのどの版でも扱える上限です |
| 順序付きディザリング | はい。`--dither` | はい。デフォルトで有効です |
| 映像の変化に合わせたパレットの再適合 | はい。シーンごと | はい。フレームごとで、収まる間は維持します |
| 追加ハードウェアなしのサウンド | はい。YM2610のADPCM-B | はい。PSGでのトーン合成 |
| サウンドの領域を映像に回す無音ビルド | 一部対応。ライブラリのバンドルではサウンドを省けます。サウンドは専用のROMにあるため、省いても映像の領域は空きません | はい。`--silent` |
| SubRipファイルからの字幕 | はい | はい。映像に焼き込むため、オフにはできません |
| 再生と一時停止 | はい | はい。本体のポーズボタン、ゲームギアではスタートボタン |
| 早送りと巻き戻し | はい。早送りは2x、5x、10x | 予定 |
| シーク | はい。10秒戻る、または進む | はい。左右で10秒間隔の地点へ移動 |
| 経過時間と総時間を表示する再生位置バー | はい | はい、一時停止中 |
| 最初からの再生と停止 | はい | はい |
| サウンドのオン、オフ | はい | はい、上 |
| 終了時に映像をループ | はい | はい |
| 診断オーバーレイ | はい | はい、一時停止中にボタン1 |
| 破損したストリームのエラー画面 | はい | はい |
| 自作ゲームへの映像の組み込み | はい。`--bundle`がそのまま組み込めるライブラリを出力します | 一部対応。`--rows`と`--columns`で小さい映像を作成できますが、そのまま組み込めるバンドルはまだありません |
| コンソールが描画する内容のプレビュー | はい。動画 | はい。動画、またはソースと並べた4フレーム |
| 全ビルドでの書き込みタイミングゲート | はい | はい |
| テスト実行ごとにベイクする回帰用の映像セット | はい。6本の映像 | はい。6本の映像 |
| 実機での動作 | はい。AESとMVS | まだです。Game Gearでの実行を待っています |
