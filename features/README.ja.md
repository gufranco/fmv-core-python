2つのプレイヤーは[FAMILY.md](../FAMILY.md)で定めた同じ機能リストに沿って作られており、この表は両方のREADMEで同じです。「予定」はまだ実装していない作業を表します。コンソールが搭載できない機能には、ハードウェア上の理由とともに「対応不可」と記載します。

| 機能 | Neo Geo | Master System |
|---|---|---|
| 動画ファイルからカートリッジまで1コマンドで作成 | はい | はい |
| 映像が画面全体を埋める。全体を覆うように拡大縮小してクロップ | はい | はい |
| ソースに焼き込まれた黒帯を検出してクロップ | はい | はい |
| 収まるまで映像と音声を最高品質から段階的に下げる | はい。`--quality search`が35段のラダーを下へ順にベイクし、音声は収まる範囲で最も高いレートを選びます | はい。カートリッジからはみ出すベイクは同じ探索でフレームレートを段階的に下げ、音声は最後に省きます |
| 追加ハードウェアなしで最大の標準カートリッジ | はい。128 MiBのキャラクターROM | はい。1 MB。Segaのマッパーのどの版でも扱える上限です |
| 順序付きディザリング | はい。`--dither`、デフォルトで無効 | はい。`--dither`、デフォルトで有効 |
| 映像の変化に合わせたパレットの再適合 | はい。シーンごと | はい。フレームごとで、収まる間は維持します |
| 追加ハードウェアなしのサウンド | はい。YM2610のADPCM-B | はい。PSGでのトーン合成 |
| サウンドの領域を映像に回す無音ビルド | はい。`--silent`。サウンドは専用のROMにあるため、省いても映像の領域は空きません | はい。`--silent` |
| SubRipファイルからの字幕 | はい | はい。映像に焼き込むため、オフにはできません |
| 再生と一時停止 | はい | はい。本体のポーズボタン、ゲームギアではスタートボタン |
| 早送りと巻き戻し | はい。早送りは2x、5x、10x | 不可能。1フレーム分の転送だけで1フィールドの59,736 Tステートのうち最大54,000を使うため、リプレイは2フレーム分を送れません。代わりに左右でシーク地点へ移動します |
| シーク | はい。CとDで10秒間隔の地点へ移動。`--seek-every`で変更可能 | はい。左右で10秒間隔の地点へ移動。`--seek-every`で変更可能 |
| 経過時間と総時間を表示する再生位置バー | はい。いずれかのボタンを押してから3秒間 | はい。いずれかのボタンを押してから3秒間と、一時停止中 |
| 最初からの再生と停止 | はい | はい |
| サウンドのオン、オフ | はい | はい、上 |
| 終了時に映像をループ | はい | はい |
| 診断オーバーレイ | はい。Select | はい。下 |
| 破損したストリームのエラー画面 | はい | はい |
| 自作ゲームへの映像の組み込み | はい。`--bundle`がそのまま組み込めるライブラリを出力します | はい。`--bundle`がそのまま組み込めるライブラリを出力し、`examples/cutscene`がそれでゲームをビルドします |
| コンソールが描画する内容のプレビュー | はい。動画、またはソースと並べた4フレーム | はい。動画、またはソースと並べた4フレーム |
